# Portfolio Website
A responsive, modern portfolio website built with HTML, CSS, and JavaScript.

## Live Demo
[brilliant-pasca-aed06e.netlify.app](https://brilliant-pasca-aed06e.netlify.app)

## Features
- Responsive design (desktop & mobile)
- Smooth scrolling navigation
- Hamburger menu for mobile
- Professional sections: Profile, About, Experience, Projects, Contact

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Installation & Usage
1. Clone the repository
2. Open `index.html` in your browser
3. Customize content in HTML and styling in CSS

## Customization
- Update personal info in `index.html`
- Modify colors and styling in `style.css`
- Add more projects in the projects section
